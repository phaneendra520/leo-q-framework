# Class Diagrams

This folder contains class-level diagrams for the project.

Files:
- `class_diagrams.md` — Mermaid and sequence diagrams for main types.
- `class_diagrams.puml` — PlantUML source for the class diagram.

Rendering:
- GitHub can render Mermaid diagrams in Markdown files.
- Use PlantUML to render `class_diagrams.puml` locally. Example (requires Java):

```bash
java -jar plantuml.jar docs/architecture/class_diagrams.puml
```
