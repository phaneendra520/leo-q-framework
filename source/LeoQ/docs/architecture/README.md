# Architecture Diagrams

This folder contains architecture diagrams for the `leo-q-framework` repository.

Files:
- `architecture.md` — high-level overview with Mermaid diagrams.
- `architecture.puml` — PlantUML source for the component diagram.

Rendering:
- GitHub can render Mermaid diagrams in Markdown files.
- Use PlantUML to render `architecture.puml` locally. Example (requires Java):

```bash
java -jar plantuml.jar docs/architecture/architecture.puml
```

Or use online renderers such as https://plantuml.com/ or VS Code PlantUML extension.
